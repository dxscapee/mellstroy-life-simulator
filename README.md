# Idle Tycoon (Яндекс Игры)

Браузерный 2D Idle Tycoon. Стек: Vite 5 + TypeScript (strict) + Pixi.js v8; UI — чистый HTML/CSS.

## Быстрый старт

```bash
npm install      # один раз: зависимости + sharp (конвертер картинок)
npm run dev      # игра: http://localhost:5050 (текстуры собираются сами)
npm run build    # прод-сборка (tsc + vite build; ассеты собираются перед сборкой)
npm run assets   # только пересобрать текстуры из art/ + отчёт и бюджеты
```

После `git clone` папки `public/assets/` ещё нет — она появляется, как только запустишь
`npm run dev` (или `npm run assets`). Это норма, а не потерянные файлы.

## Где что лежит (чтобы не путаться в текстурах)

| Путь | Что это | В git? |
|---|---|---|
| `art/<группа>/<стадия>.<ext>` | **МАСТЕРА** текстур — то, что вы рисуете и ищете как исходник | ✅ да |
| `public/assets/` | **СОБРАННЫЕ** текстуры (`*.webp` + `manifest.json`) — генерируются пайплайном | ❌ нет (собирается само) |
| `src/` | код игры: `data/` — данные, `engine/` — логика, `view/` — Pixi-сцена, `ui/` — оверлей, `services/` — Яндекс, `debug/` — dev-панель | ✅ да |
| `scripts/` | пайплайн ассетов (мастера → `public/assets/`) | ✅ да |
| `dist/` | готовая сборка | ❌ нет (генерируется) |
| `node_modules/` | зависимости (`npm install`) | ❌ нет |

**Правило:** рисуешь → кладёшь в `art/`. В `public/assets/` руками ничего не кладём и не ищем —
это результат сборки. Нужную текстуру ищи в `art/`.

Пустые папки групп в `art/` держит `art/<группа>/.gitkeep` — не удаляй их, иначе папки
исчезнут из клона напарника (git пустые каталоги не хранит).
