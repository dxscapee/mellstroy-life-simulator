# art/ — мастера текстур (ЭТА ПАПКА В GIT)

Положил файл — игра сама его подхватит. Полная инструкция: [`../ASSETS.md`](../ASSETS.md).

```
art/<группа>/<стадия>.<расширение>      например:  art/house/0.png
```

* **Папка = объект**, имя файла = номер стадии (`0` — базовая, дальше `1`, `2`, `3`),
  расширение = формат (`png/jpg/webp/avif/gif` — картинка, `mp4/webm/mov/m4v` — видео).
* Папки с суффиксом `_home` — для ДОМАШНЕЙ сцены (`furniture_home`, `camera_home`,
  `pc_home`), плюс `world_home` — фон квартиры. Без суффикса — улица.
* Файл `.gitkeep` в папке — служебный, просто держит пустую папку в git. Не удаляй.
* Собранные текстуры (то, что видит игра) лежат в `public/assets/` — эта папка тоже
  в git; руками её не правим, она обновляется командой `npm run assets`.

Размеры боксов, число стадий и список групп — в [`../src/data/sceneAssets.json`](../src/data/sceneAssets.json)
(единственный источник правды для игры и пайплайна).
